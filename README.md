# mmy-css

A modern, lightweight CSS framework under 3KB gzipped.

## Installation

```bash
npm install mmy-css
```

## Usage

In your JavaScript entry file:

```javascript
import 'mmy-css';
```

Or link directly in HTML:

```html
<link rel="stylesheet" href="node_modules/mmy-css/dist/mmy.min.css">
```

## Development

```bash
# Install dependencies
npm install

# Start local server and watch mode
npm run dev

# Build production bundle
npm run build
```
